# oe-recipe-book

### Vragen

#### Wat doet git clone?
- Maakt een kopie van van een remote git repo 
#### Welke remote alias wordt standaard aangemaakt bij een clone?
 - origin
#### Waarom gebruik je een .gitignore-bestand?
 - Voor bestanden die enkel lokaal nodig zijn en dus niet moeten gestaged worden
#### Waarom hoort een .gitignore in de root van de repository?
 - Zodat hij direct beschikbaar is en niet per ongelijk in een geignored map zit
#### Wat is het verschil tussen git push en git pull?
 - git push stuurt je commit naar de remote repo en pull haalt all commits uit de remote repo die nog niet lokaal staan
#### Waarom zijn duidelijke commit messages belangrijk wanneer meerdere personen samenwerken?
- Zodat je teamgenoten snel kunnen zien wat er gebeurt in de commit
